# Sibillini Impact · Exena

> La calzatura di sicurezza che finanzia la rinascita dei borghi montani. Tre prospettive strategiche per Exena.

Sito web istituzionale e strategico del progetto **Sibillini Impact** sviluppato per Exena.

## 🚀 Tecnologie

- **React 19**
- **Vite 7**
- **Tailwind CSS v4**
- **Framer Motion**
- **Lucide Icons**
- **TypeScript**

## 📦 Sviluppo Locale

```bash
# Installazione dipendenze
npm install

# Avvio server di sviluppo
npm run dev

# Build di produzione
npm run build
```

## 🌐 Deploy su Netlify

Il progetto include la configurazione `netlify.toml` preimpostata per il deploy automatico su Netlify collegando il repository GitHub.
- **Build command**: `npm run build`
- **Publish directory**: `dist`
